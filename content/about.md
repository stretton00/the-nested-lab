Foundation, usually several layers of virtualisation deep.

NSX VPC networking, VCF Automation, and the failure modes the documentation
doesn't mention. Everything you see here — commands, output, error messages —
was captured from a running environment. Trimmed for length, never edited
for outcome.

employer's. Everything described here was performed in a lab environment;
